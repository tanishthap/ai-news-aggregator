# ai-news-aggregator
AI News Aggregator is a multi-agent Python system that collects AI news from OpenAI, Anthropic, and YouTube, summarizes and ranks stories by relevance and significance, selects the top 10 from the past 24 hours, generates a personalized newsletter with Gemini, and delivers it via Gmail. Built with Docker and PostgreSQL.
